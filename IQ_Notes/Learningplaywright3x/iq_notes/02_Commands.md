# Windows Keyboard Shortcuts for Comments

## Single Line Comment
**Keyboard Shortcut:** `Ctrl + /`

Toggle a single-line comment on the current line or selected lines in most code editors.

**Example:**
```javascript
// This is a single-line comment
```

## Block Comment (Multi-line)
**Keyboard Shortcut:** `Shift + Alt + A`

Create or toggle a block comment for multiple lines.

**Example:**
```javascript
/* 
   This is a block comment
   spanning multiple lines
*/
```

## IDE-Specific Shortcuts

### VS Code
- **Single-line comment:** `Ctrl + /`
- **Block comment:** `Shift + Alt + A` (or use mouse to select and apply comments)

### Visual Studio
- **Single-line comment:** `Ctrl + K, Ctrl + C`
- **Uncomment:** `Ctrl + K, Ctrl + U`

### WebStorm / IntelliJ
- **Single-line comment:** `Ctrl + /`
- **Block comment:** `Ctrl + Shift + /`

## JavaScript Comment Types

### Single-line Comment
```javascript
// This explains the code
let name = "John";
```

### Multi-line Comment
```javascript
/* 
   This is a longer explanation
   that spans multiple lines
*/
const age = 25;
```

### JSDoc Comment (for documentation)
```javascript
/**
 * Calculate the sum of two numbers
 * @param {number} a - The first number
 * @param {number} b - The second number
 * @returns {number} The sum of a and b
 */
function add(a, b) {
  return a + b;
}
```
